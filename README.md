# Что
> **Иерархическая мультиагентная марковская игра с частичной наблюдаемостью, структурированным символьным состоянием и обучением с подкреплением.**

Стратегическая игра, где абсолютно все игровые сущности представлены в виде конечных автоматов. Автоматы основаны на IPO-архитектуре: входы, обработка, выходы, состояние. Персонажи, как частный случай автоматов, дополняются архитектурой BDI. Сущности существуют в среде, представляемой как открытая система (суперсистема?). У каждой сущности две метрики: энергия, как мера влияния на среду и другие сущности, и сила, как мера способности сообщения энергии. Целевая функция каждой сущности пока что выражена в максимизации силы.
