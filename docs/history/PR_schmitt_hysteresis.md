## 2. Ключевые изменения в `simulation.py`

### 2.1 Триггер Шмитта для входной восприимчивости адресата
Вместо непрерывной сигмоиды — два порога с памятью состояния:
- `input_open` открывается при накопленном давлении `w_adopt ≥ ON(F)` и закрывается при
  падении `w_adopt ≤ OFF(F) = OFF_FRAC·ON(F)` либо по истечении окна `OPEN_TTL`.
- Пороги МАСШТАБНЫЕ: `ON(F) = max(ON_MIN, ON_FRAC·F)` — выводятся из двух метрик модели
  (принятая входящая работа и сила адресата), без новых переменных.
Гистерезис даёт упорству смысл: давление может увенчаться, но не гарантированно —
ровно по замыслу автора.

### 2.2 Исправление «catch-22» (коммит `44a30dc`, гипотеза H-A)
Абсолютный порог `ON_THRESHOLD=25` делал нижнее состояние (малая сила) **недостижимым для атаки**:
агент со силой ~1 физически не мог накопить давление до порога — верхний аттрактор был
архитектурно закрыт для слабых. Решение — **масштабно-инвариантный порог**:

```python
def on_threshold(self):        # окно открывается при давлении, соразмерном силе цели
    return max(6, int(0.25 * self.force))
```

Слабая структура имеет низкое окно (проницаема для такой же слабой), сильная — высокое.
Дополнительно: `MIN_OUTPUT = 2` (выход адресанта никогда не обнуляется полностью),
UtilityAI обновлён для учёта гистерезисного состояния входа противника.

### 2.3 Чистая IPO-метрика
Удалены переменные `capital` и `resistance` как отдельные сущности; их семантика
восстановлена поверх двух метрик: резистентность = состояние `input_open` + накопленное
давление (внутренние поля автомата), «капитал» = сама сила.

### 2.4 Пул энергии
Потолок пула: `E_MAX_MULT * regen` (`E_MAX_MULT = 3`) — предотвращает тупики накопления
и позволяет малым структурам начинать экспансию.
