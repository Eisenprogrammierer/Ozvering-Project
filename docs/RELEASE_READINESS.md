> **Область действия.** Это оценочный трекер готовности к релизу, а не канон
> модели. Канон — [`SOURCE_OF_TRUTH.md`](SOURCE_OF_TRUTH.md); проектные
> решения — [`WORLD_CORE_MODEL.md`](WORLD_CORE_MODEL.md) §7; живой трекер

>
> **Идеальный конечный результат (цель релиза):** готовая среда для обучения
> интеллектуальных агентов **и** играбельная игра на этой же физике.

---

## 1. Методология оценки

Работа декомпозирована по четырём осям соответствия цели релиза:

* **A. Среда обучения** — контракты `ArenaEnv`/`CampaignEnv`, награды,
  self-play, оценка, чекпойнты, рандомизация домена;
* **B. Играбельность** — экраны (`view/`, `ui/`, арена), сохранение/загрузка,
  время/скорости, обратная связь игроку;
* **C. Модель мира** — открытые вопросы 4-2-1 (§7 `WORLD_CORE_MODEL.md`),
  баланс и калибровка;
* **D. Инженерная обвязка** — зависимости, CI, воспроизводимость, упаковка,
  документация пользователя.

Каждому пункту присвоена трудоёмкость в «человеко-неделях» (чн) при одном
разработчике, знакомом с кодовой базой, и статус: **готово / первый срез /
не начато**. Оценка — порядок величины, а не бизнес-план.

## 5. Варианты скоупа релиза

* **MVP-релиз (≈35–40 чн):** ось A (без A5/A7 — оставить табличный RL как
  baseline, кампанию оставить на дневном планировщике) + ядро оси B (B1,B2,B3,
  B6) + вся ось D. Цель «среда для обучения + игра» формально достигнута:
  обе среды работают, обучаемый агент в комплекте, игра собирается.
* **Полный релиз под идеальную цель (≈68 чн):** всё выше + A5 (непрерывное
  время кампании) + A7 (конкурентоспособный RL) + выборочное C (C2,C5).
* **Релиз v2 «зрелый мир» (+22 чн):** полное закрытие §7 (ось C).

Рекомендация: идти к MVP-релизу, а C-ось и A7 оформить как roadmap v2 — они
не блокируют ни обучение, ни игрубельность, а только глубину симуляции.

## 7. Контрольный список приёмки релиза (Definition of Done)

- [ ] `pytest -q` зелёный **с pygame-ce** (не 81 skip, а реальные прогоны GUI).
- [ ] `python3 main.py` открывает единое меню → кампания/арена/редактор без ручных флагов.
- [ ] `python3 -m agents.train --env arena --episodes <N>` выдаёт обученный чекпойнт в `checkpoints/`, и игра его автоподхватывает.
- [ ] Held-out матрица силы показывает непустой win-rate отличные от baseline (или явно задокументированный потолок).
- [ ] Кампания: хотя бы одна сюжетная арка проходится до win/lose в ручном и автопилот-режиме.
- [ ] Сейв/лоад переживает перезапуск и смену версии схемы.
- [ ] Собран устанавливаемый пакет/бинарь хотя бы для одной платформы.
- [ ] CHANGELOG + тег vX.Y.Z + README «как играть / как обучить агента».
- [ ] CI включает e2e-смоук GUI и пин версий инструментов.
