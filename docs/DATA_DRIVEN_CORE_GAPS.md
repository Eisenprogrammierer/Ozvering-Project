## 4. Критерии готовности

Ядро считается Data-Driven, когда новый орган, убеждение, намерение,
актив, условие, эффект и правило ИИ добавляются JSON-ом без правки
Python, неизвестный ключ даёт ошибку загрузки, а старые сейвы и контракт
16 потребностей сохраняются.
