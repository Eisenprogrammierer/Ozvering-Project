# INTERACTION.md — доменно-нейтральный экран взаимодействий

Экран отвечает на три вопроса игрока:

1. **С кем можно взаимодействовать?** — список объектов (`Target`);
2. **Что с ними можно сделать?** — действия выбранного объекта (`ActionSpec`),
   панель раскрывается только после выбора объекта;
3. **Что может произойти?** — шумный прогноз исходов (`OutcomeSpec` /
   `OutcomeForecast`) и, после выполнения, фактический результат.

Это **заготовка**, а не готовая игровая механика: в пакете нет диалогов,
отношений, экономики, боя или конкретных персонажей. Слой можно подключить к
будущему контенту, не меняя канон `simulation.py` / `warfare.py`.

## Запуск

```bash
python3 main.py                         # меню → «Взаимодействие»
python3 main.py --interaction           # сразу экран взаимодействий
python3 main.py --scene interaction     # то же через общий --scene
```

Для запуска нужен `pygame-ce` (как и для остального сценного слоя `ui/`).
Чистая модель `interaction/` от pygame не зависит.

## Три слоя модели

### 1. Объекты: `Target`

```python
Target(
    id="alpha",
    label="Субъект «Альфа»",
    description="Нейтральный контакт.",
    tags=("нейтральный",),
    actions=(TALK, OFFER),
    available=True,
)
```

`available=False` скрывает объект из `available_targets()` и запрещает его
выбор. `actions` — кортеж действий, доступных именно этому объекту.

### 2. Действия: `ActionSpec`

```python
ActionSpec(
    id="press",
    label="Оказать давление",
    description="Принуждение; прогноз особенно ненадёжен.",
    outcomes=(...),
    uncertainty=0.45,
    unknown_share=0.05,
    enabled=True,
)
```

* `outcomes` — относительные веса возможных исходов; модель нормализует
  `OutcomeSpec.probability`, поэтому сумма не обязана быть ровно `1.0`;
* `uncertainty` — дополнительный шум прогноза (`0..1`);
* `unknown_share` — доля эффектов, которых **нет** в известной модели. Она
  показывается отдельной строкой «Неизвестный исход» и может выпасть при
  выполнении;
* `enabled=False` скрывает действие из `actions_for()`.

### 3. Исходы: `OutcomeSpec` и `OutcomeForecast`

```python
OutcomeSpec(
    id="strain",
    label="Напряжение",
    description="Отношения слегка ухудшаются.",
    probability=0.14,
    uncertainty=0.18,
    hidden=False,
    tone="warning",
)
```

`tone` — подсказка для цвета в UI (`positive`, `negative`, `warning`,
`neutral`, `unknown`).

Прогноз (`OutcomeForecast`) — не одно число, а **диапазон**:

* `low`/`high` — границы вероятности;
* `confidence` — уверенность (`1 - шум`);
* `known=False` — вероятность неизвестна;
* `hidden=True` — скрытый исход; его настоящий ярлык не показывается до
  выполнения;
* `unknown=True` — синтетический «неизвестный исход» из `unknown_share`.

`probability_text` даёт готовую строку для UI, например
`~14-81% · уверенность 33%` или `вероятность неизвестна`. Диапазоны
**независимы** и не обязаны суммироваться в 100%: это оценка с шумом, а не
точная таблица вероятностей.

## `InteractionModel`

```python
from interaction import demo_model

model = demo_model(seed=7)
model.available_targets()          # список объектов
model.select_target("alpha")       # объект выбран, действие сброшено
model.actions_for()                # действия только выбранного объекта
model.select_action("press")       # действие выбрано
model.forecasts()                  # шумные прогнозы
result = model.resolve()           # фактический исход
model.history                      # все выполнения в этой сессии
model.snapshot()                   # сериализуемый снимок
```

Свойства:

* прогнозы **стабильны и кешируются** для пары `(target, action)`;
* выполнение использует последовательный `random.Random(seed)`, поэтому
  одинаковый seed и одинаковая последовательность выборов дают одинаковую
  историю;
* `select_target` сбрасывает действие и последний результат;
* `clear_selection` сбрасывает только выбор; `reset` дополнительно очищает
  историю и возвращает RNG к исходному seed;
* `resolve` выбирает исход по весам, а при срабатывании `unknown_share`
  возвращает результат с `unknown=True`;
* действие без исходов даёт нейтральный результат «Нет наблюдаемого эффекта».

### Свой контент

Достаточно собрать `Target`/`ActionSpec`/`OutcomeSpec` и передать их в
`InteractionModel`. Демонстрационный набор — `interaction/demo.py`; он
специально абстрактный (субъекты «Альфа»/«Бета», нейтральные действия и
исходы), чтобы его можно было заменить без изменения UI.

Экран принимает готовую модель или seed при переходе:

```python
app.go("interaction", model=my_model)   # свой контент
app.go("interaction", seed=42)          # демо с воспроизводимым seed
```

## Экран `ui/scenes/interaction.py`

Три колонки:

| Панель | Что показывает | Когда раскрывается |
|---|---|---|
| Слева | доступные объекты | всегда |
| В центре | действия выбранного объекта | после выбора объекта |
| Справа | прогнозы исходов и неизвестные | после выбора действия |

Управление:

* ЛКМ — выбрать объект или действие;
* колесо мыши — прокрутка длинных списков;
* `Enter` — выполнить выбранное действие;
* `R` — сбросить выбор;
* `Esc` / «В меню» — вернуться в главное меню.

Нижняя строка показывает подсказку, а после выполнения — фактический исход и
его описание. Цветовая полоса строки отражает `tone` исхода; «неизвестные»
строки не раскрывают скрытый ярлык.

Сцена только читает модель и раздаёт ввод. Логика прогнозов и розыгрыша
находится в `interaction/`, поэтому её можно тестировать без pygame.

## Границы

* Это **не** система диалогов, отношений или боевых проверок. Нет требований,
  последствий для мира, истории или сохранения между запусками.
* `InteractionModel` не меняет `Target`/`ActionSpec`; если будущей механике
  нужно менять состояние мира, это стоит делать отдельным слоем-адаптером.
* Демо-подписи русскоязычные; статические подписи экрана двуязычны через
  `App.t`. Для полноценной локализации контента можно добавить пары
  `label_ru/label_en` или отдельный словарь.
* Шум прогноза — детерминированная модель, а не статистическая калибровка.
  Для реальной игры её можно заменить своим резолвером, сохранив контракт
  `forecasts()` / `resolve()`.

## Тесты

```bash
pytest -q tests/test_interaction.py     # чистая модель, без pygame
pytest -q tests/test_ui.py              # экран под headless SDL (если pygame есть)
```

`tests/test_interaction.py` проверяет раскрытие действий, стабильность и шум
прогнозов, скрытые/неизвестные исходы, детерминизм по seed, историю и снимок.
`tests/test_ui.py` проверяет, что экран рисуется, действия появляются после
выбора объекта, прогнозы — после действия, и что кнопки вписываются в окна
640×480, 1024×640 и 1920×1080.
