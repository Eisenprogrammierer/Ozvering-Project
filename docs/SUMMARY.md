# Краткий обзор проекта

> **Роль.** Сжатый вход в проект и указатель на актуальные документы.
> Это **не** источник истины. Канон — [`SOURCE_OF_TRUTH.md`](SOURCE_OF_TRUTH.md),
> целевая модель — [`WORLD_CORE_MODEL.md`](WORLD_CORE_MODEL.md), текущий
> дневной мир — [`WORLD.md`](WORLD.md), кампания автоматов —
> [`AUTOMATA_CAMPAIGN.md`](AUTOMATA_CAMPAIGN.md). При расхождении верны они.

## Что это

`Ozvering-Project` — симуляция мира, где все сущности описаны одной
онтологией **4-2-1**: входы, выходы, обработчики, состояния; сила `F` и
энергия `E`; работа `W`. Персонажи дополнительно имеют BDI. Предметы
сознания не имеют, но могут действовать через обработчики.

Три слоя сосуществуют и не смешиваются:

| Слой | Роль | Где |
|---|---|---|
| `core41/` + `agents/` | целевой срез 4-2-1 и обучаемые политики арены | `core41/`, `agents/` |
| Кампания автоматов | фракции, органы, работы, BDI персонажей, реальное время | `campaign/automata.py`, `configs/campaigns/` |
| Дневной мир `world_actor` | должности, свободная жизнь, `WorldEngine` | `campaign/world.py`, `configs/worlds/` |

`simulation.py` остаётся легаси-каноном дуэлей; активные сцены его не
используют. Целевая модель и текущая реализация различаются осознанно,
различия зафиксированы в [`SOURCE_OF_TRUTH.md`](SOURCE_OF_TRUTH.md) §4.

## Ключевые инварианты

1. Любое изменение состояния — через работу: вход, обработчик, состояние
   получателя.
2. Одна универсальная энергия. Форма работы (`force`/`info`) — канал, а не
   отдельная валюта.
3. BDI есть только у сознающих сущностей; предметы — автоматы без BDI.
4. Время физическое: при `1×` одна реальная секунда равна одной игровой.
   Ускорение — явный множитель, пауза/замедление ниже `1×`/rewind
   запрещены. Свободные сутки — `86400` секунд.
5. Персонаж — субъект: личная цель, доверие, обида и память приказов
   влияют на выбор и эффект работы (`ai_model.character_agency`).
6. Победа не объективна; есть цели сценария и условия поражения.

## Запуск

```bash
python3 main.py              # клиент view/
python3 main.py --arena      # арена
python3 main.py --automata   # редактор автоматов
venv/bin/python -m pytest -q  # тесты
```

Полный маршрут по режимам, окружению и отладке — [`ONBOARDING.md`](ONBOARDING.md).
Команды и контрибьютинг — [`HOWTO.md`](HOWTO.md), `README.md`.
