# UI.md — сценный (2-D экранный) слой

Документ описывает **традиционную игровую оболочку** Ozvering-Project: экраны
(меню, настройки, сохранения, нарратив, игровое поле) поверх слоя наблюдения за
партией. Слой живёт в пакете [`ui/`](../ui) и **не изменяет модель**
(`simulation.py`) — как и `game_engine.py`, он использует только публичное API.

Сфера ответственности: **экраны, кнопки, нарратив, метрики и система
сохранений**. Персонажи, локации, 2-D арт и 3-D сцены — отдельные задачи, в этот
слой не входят (ниже — «Плейсхолдеры»).

## Запуск

```bash
pip install pygame-ce
python3 -m ui                 # обычный запуск (старт — главное меню)
python3 -m ui --fullscreen    # (или -f) полноэкранный режим
python3 -m ui --scene game    # сразу открыть экран (отладка)
```

`game_engine.py` по-прежнему запускается автономно (`python3 game_engine.py`) —
это прежний одиночный экран «арена + HUD». Сценный слой встраивает тот же
экран как сцену `game`; см. раздел «Встраивание» ниже.

## Карта экранов

| Экран | Модуль | Назначение |
|-------|--------|-----------|
| Главное меню | `ui/scenes/menu.py` | Новая партия, Продолжить (автосейв), Загрузить, Настройки, Об игре, Выход |
| Настройки | `ui/scenes/settings.py` | Полный экран, автосохранение, язык, громкости, скорость текста |
| Сохранения | `ui/scenes/saves.py` | Слоты автосейва и ручные 1–3: загрузить/сохранить/удалить |
| Нарратив | `ui/scenes/narrative.py` | Страницы вступления (плейсхолдер-иллюстрация + текст) |
| Игровое поле | `ui/scenes/game.py` | Обёртка над `game_engine.GameApp` (арена + HUD) |
| Пауза | `ui/scenes/pause.py` | Оверлей поверх партии: Продолжить, Сохранить, Настройки, Меню |
| Об игре | `ui/scenes/about.py` | Сведения о проекте и подсказки по управлению |

Навигация: мышь (клик = клавиша); в партии — клавиши движка (`SPACE`, `S`,
`[`/`]`, `M`, `1..7`, `R`, `F1/H`); `ESC` в партии открывает паузу, `F11` —
полный экран в любом экране. Клавиатурная навигация по меню — задел на будущее.

## Архитектура

```
ui/
  __init__.py        # не импортирует pygame (save/content доступны без GUI)
  theme.py           # палитра, метрики, рисование панелей/плейсхолдеров
  widgets.py         # Button / Toggle / Slider / Label / Placeholder
  save.py            # SaveManager: настройки и слоты (JSON, атомарная запись)
  content.py         # нарратив и тексты (двуязычно, ru/en)
  scene.py           # Scene (базовый класс) + SceneManager (стек экранов)
  app.py             # App: окно, шрифты, главный цикл, роутинг, настройки
  scenes/            # конкретные экраны (см. таблицу выше)
  __main__.py        # точка входа `python -m ui`
```

* **`Scene`** — один экран: `on_enter/on_exit`, `layout(w, h)`, `handle_event`,
  `update(dt)`, `draw(surface)`.
* **`SceneManager`** — стек сцен: `go` (сменить корневой экран), `push`/`pop`
  (оверлеи). Экземпляры в стеке сохраняются, поэтому пауза не сбрасывает партию:
  при `pop` восстанавливается тот же объект `GameScene`.
* **`App`** владеет окном PyGame и шрифтами и переиспользует из `game_engine.py`
  `FontSet`, `compute_window_size`, `_probe_font` и логгер (`GAME_LOG`).
* Слои `overlay` рисуются поверх нижележащей сцены (полупрозрачное затемнение) —
  так устроена пауза.

## Система сохранений и автосохранений

Каталог `saves/` (в корне репозитория; добавлен в `.gitignore`):

| Файл | Назначение |
|------|-----------|
| `settings.json` | Пользовательские настройки (язык, автосохранение, громкости, скорость текста, полный экран) |
| `autosave.json` | Автосохранение (пишется при старте и завершении партии, а также при выходе в меню) |
| `slot_1..3.json` | Ручные слоты (кнопка «Сохранить» из паузы) |

Запись — атомарная (временный файл + `os.replace`), UTF-8. Битый JSON не роняет
приложение: чтение возвращает `None` и пишет предупреждение в лог.

Формат слота — метаданные партии:

```json
{ "version": 1, "name": "match", "created": "...", "updated": "...",
  "seed": 3, "tick": 128, "winner": null, "finished": false,
  "steps": 2000, "with_env": true,
  "profile_rl": "CANON", "profile_ai": "CANON" }
```

**Возобновление партии.** Полное состояние партии не сериализуется: движок
(`MatchEngine`) детерминирован по `seed`, поэтому «Продолжить»/«Загрузить»
пересоздают партию с сохранённым seed и **доигрывают до сохранённого такта**
(`game_engine.GameApp.start_match(seed, resume_tick)`) — состояние
реконструируется повторным проигрыванием. Ограничение осознанное: сериализация
внутреннего состояния агентов/среды избыточна, пока партия воспроизводима.

## Встраивание игрового поля (изменения `game_engine.py`)

`GameApp` получил **обратно совместимые** параметры, превращающие его в сцену:

* `GameApp(fonts, screen=None, on_escape=None, seed, steps, with_env,
  profile_rl, profile_ai)`: при переданном `screen` окно не создаётся — рисуем в
  чужой surface;
* `draw(surface=None)` — при `surface is None` поведение прежнее (рисуем в своё
  окно и делаем `flip`); с чужим surface `flip` делает вызывающий;
* `handle_events(events=None)` — при `None` берём события из очереди pygame
  (автономный режим), иначе обрабатываем переданный список (сценный слой);
* `on_escape` — `ESC` вызывает колбэк (открыть паузу) вместо выхода;
* `on_resize(w, h)`, `start_match(seed, resume_tick)`, `progress()`,
  `new_match(seed=None)` — вспомогательное API для сценного слоя.

Проверено, что одиночный режим (`python3 game_engine.py`) работает как раньше.

## Плейсхолдеры и дальнейшие шаги

* Вместо ассетов используется `theme.draw_placeholder` — рамка с диагоналями и
  подписью `[ IMG: <ключ> ]`. Ключи: `menu_hero`, `intro_arena`,
  `intro_transfer`, `intro_conjuncture`, `about_logo`.
* Следующие шаги (вне этого слоя): реальные 2-D ассеты (фон, иконки, кнопки),
  звук/музыка (ползунки громкости уже сохраняются), клавиатурная навигация по
  меню, локальные профили игрока. Персонажи и локации — 3-D слой в рамках
  другого проекта.

## Тесты

`tests/test_ui.py`:

* без графики (работают в CI без pygame) — настройки, слоты, битый JSON,
  двуязычный контент, «`ui.save` свободен от pygame»;
* с графикой (`pytest.importorskip("pygame")`, `SDL_VIDEODRIVER=dummy`) —
  старт в меню, отрисовка всех экранов, нарратив → партия и автосейв, пауза
  сохраняет партию, сохранение/загрузка слота, клик по кнопке.

Ручной headless-прогон (без assert-обвязки) полезен при отладке:

```bash
SDL_VIDEODRIVER=dummy python3 -m ui --scene menu
```
