# Свободный режим: RTS-время и бесконечная песочница

> Решение от 2026-11-15. Документ фиксирует требования до реализации и
> описывает данные, по которым режим расширяется без правки Python-ядра.

## 1. Решение

Свободный режим (`free_citizen` + `free_life`) — это **бесконечная
песочница с RTS-временем**, а не дневная кампания с главой и финалом.

Инварианты:

1. Время идёт непрерывно, пока открыт экран мира. Одна реальная секунда
   равна одной игровой секунде при `1x`; физические сутки —
   `seconds_per_day = 86400`. Контент не может скрытно ускорить базовый
   темп.
2. Скорость — множитель `>= 1x`. Игрок может ускорять время и снижать
   ускорение, но не может замедлить само течение времени ниже `1x`.
3. Отрицательный `dt`, откат дней и любая форма rewind запрещены.
4. Нет обязательного финала: `world_outcome`, глава мира и дедлайн не
   завершают свободную жизнь.
5. Новые скорости, длительность дня и режим песочницы задаются JSON-полями
   мира; Python не содержит списка миров или свободных профессий.
6. Божества в свободный режим и в новые примитивы не добавляются.

## 2. Время

### 2.1. Модель

`FreeClock` — отдельный слой поверх `WorldEngine`. Он не меняет правила
мира и не хранит объективные факты: часы только решают, сколько дней и
внутридневных слотов нужно просимулировать.

- `seconds_per_day` — длительность суток в физических секундах; в мире
  Агоры это `86400`, то есть ровно одни реальные сутки на `1x`;
- `time_speeds` — упорядоченный список множителей, каждый `>= 1`;
- `speed` — текущий множитель;
- `acc` — накопленные секунды внутри текущих суток;
- `speed_up()` / `slow_down()` — переход к соседнему уровню;
- `advance(dt)` — `dt` умножается на `speed`, отрицательные значения
  отбрасываются, возвращается число завершённых дней.

Внутридневные события идут через `WorldEngine.tick(max_slot=...)`;
переход суток — через `WorldEngine.end_day()`/`advance_days()`. Это
сохраняет детерминизм, планировщик `IntentQueue` и существующие снимки.

### 2.2. Управление

- В шапке мира видны день, время суток и текущая скорость.
- В нижней панели есть кнопки `−`/`+` и подпись `1x`, `2x`, `4x`, `8x`.
- Клавиши `-` и `+`/`=` делают то же самое.
- Кнопки «Завершить день» в свободном режиме нет: день наступает сам.
- На `1x` кнопка `−` неактивна; выше максимума неактивна `+`.
- Паузы и перемотки нет. Остановка времени возможна только вместе с
  завершением симуляции (смерть/распад), а не как пользовательский
  контроль скорости.

### 2.3. Сон и загрузка

Снимок свободного режима хранит `clock` рядом с миром:

```json
{
  "clock": {
    "seconds_per_day": 86400.0,
    "speed": 2.0,
    "acc": 13.5,
    "days": 4
  }
}
```

Старые сейвы без `clock` получают скорость `1x` и нулевой остаток суток.
Загрузка восстанавливает день мира и остаток суток; это восстановление
состояния, а не внутриигровая перемотка.

## 3. Бесконечная песочница

Мир может объявить себя песочницей:

```json
{
  "sandbox": true,
  "realtime": true,
  "seconds_per_day": 86400,
  "time_speeds": [1, 2, 4, 8]
}
```

- `sandbox: true` отключает блок `storyline`, `deadline_day`,
  `win`/`lose`/`neutral` и сообщение о «пройденном горизонте».
- `realtime: true` включает `FreeClock` и автоматический ход времени на
  экране мира.
- `free_life` не содержит `win_conditions`/`lose_conditions` и
  win/lose-сцен. Другие сюжеты могут по-прежнему использовать главы.
- `infinite` остаётся страховкой движка, но песочница не должна зависеть
  только от него: глава может быть описана в JSON мира.

## 4. Данные и расширение

Добавление нового мира, архетипа или скорости не требует правок Python:

- новый архетип — `configs/characters/archetypes.json` и `free_start`;
- новая стартовая точка — `free_start` в сюжете;
- новая скорость — `time_speeds` в мире;
- другая длительность суток — `seconds_per_day`;
- другой режим — `sandbox`/`realtime` в мире.

Новые механики действий по-прежнему добавляются через реестры и
`ActionSpec` (P3/P4), а не через ветвления по id в Python.

## 5. Границы и текущий срез

- Действия кампании больше не мгновенные: `start_action` занимает слот,
  подготовка длится часы и дни, а эффект разворачивается отдельными
  импульсами с поправкой на обстоятельства. Длительности задаются
  `template.duration`/`duration_class`, окно эффекта —
  `action_process.effect_window`; см. `CONTENT_ROADMAP.md`.
- В свободном режиме действует тот же принцип: пока идёт длительная
  работа, мир продолжает жить. `FreeClock` и кампанийный
  `advance_realtime` соблюдают физическое соответствие: при `1x` реальная
  секунда даёт игровую секунду, а ускорение — только явный множитель.
  Длительные работы идут параллельно жизни мира, а не «замирают» его.
- Организационный такт равен игровым суткам, и BDI персонажей проживает
  их целиком: `bdi_routine` даёт сон, еду и уход в меру снабжения и
  готовности организации. Без этого люди умирали от голода за два дня.
- Локальная сцена с публикой и бытовыми работами — P6.
- Диалог остаётся read-only и без LLM.
- Божества не добавляются.

## 6. Проверки

- `test_free_clock.py`: скорость `>= 1`, ускорение/снижение, отсутствие
  rewind, снимок/загрузка.
- `test_free_mode.py`: `sandbox`/`realtime` в production-мире, отсутствие
  win/lose, автоматический ход дней, кнопки скорости, сохранение часов.
- `test_world.py`: `sandbox` отключает главу и горизонт, но не ломает
  миры с `storyline`.
