# Эксперименты

Все скрипты запускаются **из корня репозитория** (они сами добавляют родительскую
директорию в `sys.path`, но логи пишутся относительно cwd):

```bash
python3 experiments/exp_schmitt_suite.py   # пороги Шмитта, матрица дуэлей, дребезг
python3 experiments/exp_hypotheses.py      # конкурентные гипотезы H1-H3 о провалах RL
python3 experiments/exp_fix.py             # проверка лечения H-A (сетка ON x DECAY)
python3 experiments/exp_suite.py           # ранние дуэли Worker/Patient/Passive (истор.)
python3 experiments/exp_diag*.py           # диагностика (истор.)
```

- `treatments/` — замороженные изолированные копии модели для проверки гипотезы H-A
  (не актуальная модель; история эксперимента).
- `*.log` — сохранённые выводы прогонов на момент фиксации соответствующих коммитов
  (снимки разных калибровок — цифры между ними различаются). Актуальный срез
  дуэлей на текущей модели — `exp_fix_rerun.log`.
