# История экспериментов

Скрипты ранних слоёв механики (S-кривая, «Клаузевиц-фронты», v2-онтология),
**не запускаемые против текущей модели** `simulation.py`: они ссылаются на
удалённые API (`heal_depletion`, `pressure_yield`, класс `Worker` и др.).

Сохранены как артефакты обсуждения (ср. `docs/history/`). Актуальные проверки
и инструкции — в `experiments/README.md`.
