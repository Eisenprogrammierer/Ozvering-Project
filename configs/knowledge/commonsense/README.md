# Факты здравого смысла

Небольшая база плоских фактов «субъект — отношение — объект». Она нужна
как подсказка для диалога и мира: распознать речевой акт или режим разговора,
понять причину эмоции, назначение предмета. Это **не канон мира** и не
замена диалоговой онтологии, `configs/dialogue/` и `campaign/dialogue/`.

## Происхождение

`raw/` — исходные выгрузки, дистиллированные из
`mistralai/Mistral-7B-Instruct-v0.3` и принятые без ручной проверки.
Загрузчик их не читает; они лежат только для провенанса.

Верхнеуровневые `*.jsonl` — курированный слой:

- английские строки и мусорные таксономии исходников отброшены;
- повторные и самоссылочные факты удалены;
- речевые акты сведены к словарю проекта: `apology`, `beg_pardon`,
  `bless`, `command`, `confess`, `console`, `flirt`, `oath`, `offer`,
  `promise`, `propose`, `threat` плюс общие `request`, `question`,
  `statement`, `agreement`, `refusal`, `greeting`, `farewell`, `thanks`,
  `suggestion`, `warning`, `invitation`, `condolence`, `compliment`,
  `insult`, `denial`;
- режимы разговора: `argument`, `consolation`, `flirtation`, `insult`,
  `poetry`, `quarrel`; связь режима со стилем ответа задаёт
  `schema.json.style_hints` (`argument → official`,
  `consolation → friendly`, `flirtation/poetry → romantic`,
  `insult/quarrel → hostile`);
- факты дополнены вручную: причинно-следственные связи социальных
  действий, свойства и назначение предметов мира.

## Формат

Одна строка — один факт:

```json
{"s": "простите", "r": "IsA", "o": "apology", "weight": 0.9,
 "lang": "ru", "origin": "curated", "source": "author"}
```

Поля:

| Поле | Значение |
|---|---|
| `s` | субъект, фраза, причина |
| `r` | отношение из `schema.json.relations` |
| `o` | объект, акт, режим или следствие |
| `weight` | уверенность `0..1` |
| `lang` | язык, сейчас `ru` |
| `origin` | `curated` (проверено) или `llm` (сырьё) |
| `source` | `author` или `seed` |

Файлы:

| Файл | Содержимое |
|---|---|
| `speech_acts.jsonl` | фраза → речевой акт (`IsA`) |
| `mode_markers.jsonl` | маркер → режим разговора (`UsedIn`) |
| `social_causes.jsonl` | причина → эмоция/результат (`Causes`, `ResultsIn`, `Prevents`, `Reduces`, `Increases`, `UsedFor`) |
| `entities.jsonl` | предмет → класс/свойство/назначение (`IsA`, `HasProperty`, `UsedFor`) |

Важно: `schema.json` задаёт допустимые отношения, акты, режимы, подсказки
стиля и правила для каждого файла. Новый файл, отношение или пара
«режим → стиль» подключаются правкой схемы, а не Python.

## Проверка и запросы

```bash
python -m campaign.commonsense --check
python -m campaign.commonsense --stats
python -m campaign.commonsense "Прости меня, я был неправ"
```

`--check` проверяет JSON, вес, язык, происхождение, отношение, дубликаты,
самоссылки, обязательные файлы и ссылки `style_hints` на известные
режимы. Ошибка данных — громкая, как и в `campaign.content_lint`.

`classify("…")` возвращает `Reading` с актами, режимами, стилями и
основаниями. В консоли D7.0 та же подсказка доступна командой
`/смысл <фраза>` (или `/sense`): она ничего не меняет в мире и только
показывает, что факты говорят о фразе. Корпус парафраз
`configs/dialogue/paraphrases.json` помечает записи, выросшие из этой
базы, полем `"source": "commonsense"`.

## Границы

- Сопоставление поверхностное: фраза ищется как отдельное слово или
  оборот. Формы слов нужно добавлять в данные (`любовь`, `любви`,
  `любовью`), а не надеяться на стеммер.
- Веса не откалиброваны по игре: это приоритет подсказки, а не
  вероятность.
- Набор подключён к диалогу как подсказка, источник корпуса парафраз
  и runtime-хук стиля: `classify` не участвует в каноническом разборе
  и не переопределяет ответ персонажа. `style_hints` применяются к
  разобранной реплике, если вес маркера не ниже `hint_min_weight`, а
  `hint_priority` в `style_context.json` выше приоритета совпавших
  правил; явный стиль игрока побеждает всегда.
